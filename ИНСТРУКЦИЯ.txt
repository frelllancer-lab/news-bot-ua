=====================================================
         MEME BOT - ИНСТРУКЦИЯ ПО ЗАПУСКУ
=====================================================

ШАГ 1: Создай Telegram бота (2 минуты)
--------------------------------------
1. Открой Telegram, найди @BotFather
2. Напиши ему: /newbot
3. Придумай имя бота (например: MyMemeBot)
4. Придумай username (должен заканчиваться на "bot")
   Например: my_memes_2026_bot
5. BotFather даст тебе ТОКЕН - скопируй его

ШАГ 2: Узнай свой Chat ID (1 минута)
--------------------------------------
1. Открой Telegram, найди @userinfobot
2. Напиши ему любое сообщение
3. Он покажет твой Chat ID - скопируй его

ШАГ 3: Заполни файл .env
--------------------------------------
Открой файл .env рядом с meme-bot.exe в блокноте
и вставь свои данные:

   TELEGRAM_BOT_TOKEN=вставь_сюда_токен_от_BotFather
   TELEGRAM_CHAT_ID=вставь_сюда_свой_Chat_ID

Остальные поля можешь не трогать.

ШАГ 4: Запусти бота
--------------------------------------
Дважды кликни на meme-bot.exe

Или в командной строке:
   meme-bot.exe              - автопостинг каждые 2 часа
   meme-bot.exe --once       - запостить один мем сейчас
   meme-bot.exe --status     - показать статистику
